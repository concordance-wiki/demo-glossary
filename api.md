# API

An [entity](entity.md) of [type](type.md) `api`: an interface another system calls, with its protocol, its exposure, its version, its consumers and the objects it gives access to, and the [contract](contract.md) that describes it, which the [contract import](contract-import.md) turns into [operations](operation.md). The page of an API lists its operations and carries the contract viewer; an API that nothing consumes yields `W-API-NOCONSUMER`.
