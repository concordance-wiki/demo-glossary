# Configuration repository

The repository that holds the [configuration](configuration.md), the [profile](profile.md) override, the [theme](theme.md), the stopword files, the [lock](lock.md) and the pipeline that builds the [site](site.md) and publishes it, and no content: the notes stay in the [knowledge repositories](knowledge-repository.md) it declares as sources. Copying it is how a wiki of one's own starts.
