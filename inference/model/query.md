# Query

A reading of the [model](model.md) from the command line, without the site: `concordance query` resolves an expression the way the recognition reads a note, then prints what the model knows about it, where it is used, what it is linked to and the decisions that touched it, or answers a question of the whole corpus, in a compact text made for a person at a terminal or for the context of an agent, every fact with its file and line. The answer is as fresh as the last build, and says so.
