# Configuration repository

The repository that holds the [configuration](configuration.md), the [profile](profile.md) override, the [theme](../../publication/site/theme.md), the stopword files, the [lock](lock.md) and the pipeline that builds the [site](../../publication/site/site.md) and publishes it, and no content: the notes stay in the [knowledge repositories](../sources/knowledge-repository.md) it declares as sources. Copying it is how a wiki of one's own starts.
