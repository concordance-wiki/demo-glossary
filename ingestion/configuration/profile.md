# Profile

The YAML file that describes the meta-model: types, their attributes, the relations and the pairs of types they may join, the sections whose heading maps to a relation, the [confidence](../../inference/links/confidence.md) scale, the display rules. The engine knows nothing else. A project profile is merged over the default one; adding a type never requires a code change.
