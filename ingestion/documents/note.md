# Note

A markdown file that the [type cascade](../typing/type-cascade.md) recognises as a typed [entity](../../inference/model/entity.md): a screen, a rule, a business object, an API, a process, a decision, a term. A note has a page made of its rendered markdown first, at most five declared properties, then the [occurrences](../../inference/recognition/occurrence.md) found elsewhere.
