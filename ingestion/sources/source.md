# Source

A git repository, or a local folder, declared in the configuration with its typing rules. Every entity's identifier starts with the name of its source, and every occurrence knows which source it came from.

## Not to be confused with

The [source of a link](../../inference/links/link-source.md), which is the file, line and method a link was inferred from.
