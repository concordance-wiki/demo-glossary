# Twin resources

Several files that are forms of the same [document](../documents/document.md): a slide deck, its markdown notes, the transcript of the meeting where it was shown. The tool scores their likeness (same base name, same title, similar text, same commit, or an explicit declaration) and merges them into a single page with tabs when the score is high enough. Below that, it reports a candidate and waits for the [lock](../configuration/lock.md).
