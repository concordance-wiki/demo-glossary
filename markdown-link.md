# Link

A markdown link written by an author in a [note](note.md), such as `[annual cap](../rules/annual-cap.rule.md)`. It is the strongest evidence the tool knows: a written link produces a typed [link](link.md) at confidence 1.00, above anything inferred.

## Not to be confused with

A [link](link.md) of the model, which may come from a written link or from inference.
