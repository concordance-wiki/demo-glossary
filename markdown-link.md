# Link

A markdown link written by an author in a [note](note.md), such as `[publication threshold](../rules/publication-threshold.rule.md)`. It is the strongest evidence the tool knows: a written link produces a typed [link](link.md) at confidence 1.00, above anything inferred. On the entity page it is rendered as a plain underlined link to the page of its target, which tells it apart from a [recognised word](recognised-word.md).

## Not to be confused with

A [link](link.md) of the model, which may come from a written link or from inference.
