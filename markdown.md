# Markdown

The only syntax the tool reads: CommonMark, the tables and task lists of GFM, and an optional YAML [frontmatter](frontmatter.md). No wikilink, no directive, no proprietary tag: every [note](note.md) stays readable without the tool, and structured information goes through the frontmatter, the [sections](section.md) and the lists. A note is rendered to sanitised HTML at build, raw HTML dropped, its written links turned into page links.
