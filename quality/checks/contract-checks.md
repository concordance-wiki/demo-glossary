# Contract checks

The [check family](check-family.md) of the APIs and their [contracts](../../inference/contracts/contract.md): `W-CONTRACT-UNREACHABLE`, a contract the [contract import](../../inference/contracts/contract-import.md) could not fetch, read or parse; `W-OPERATION-AMBIGUOUS`, two operation notes claiming one imported [operation](../../inference/contracts/operation.md), or one note matching several; `W-API-NOCONSUMER`, an API nothing consumes; `W-API-CONSUMER-MISMATCH`, a declared consumer that never cites the API, or a citing note the API does not list.
