# Finding

The result of a [check](../checks/check.md) on an [entity](../../inference/model/entity.md), a [link](../../inference/links/link.md) or a file: an identifier, a [severity](severity.md), a file and line, a message and a [remediation](remediation.md). A content anomaly becomes a finding, never a crash. The build fails only when the configuration says so; the linter fails from the severity it is told to fail on.
