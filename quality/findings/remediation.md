# Remediation

The sentence every [finding](finding.md) carries saying what to change: add the note, fix the path, declare the domain. It comes from the catalogue of the [check](../checks/check.md), the same for the build and the [linter](../linter/linter.md), and every finding line ends with the address of the documentation page of the check, whose "How to fix" section says more. The JUnit report shows the remediation with the message so that a merge request reads it without opening the page.
