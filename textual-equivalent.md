# Textual equivalent

The structured text that accompanies every graphical view of the site and carries the same information: the list of neighbours next to the neighbourhood map, each with its [entity](entity.md), its type and the nature of the [link](link.md). It is present in the served HTML, so the search index reads it and a screen reader announces it; the graphic is hidden from assistive technologies and the text is authoritative.
